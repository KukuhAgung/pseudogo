Percabangan (If-Else)

Percabangan digunakan untuk mengeksekusi blok kode tertentu hanya jika sebuah kondisi logika terpenuhi (bernilai true). Aplikasi ini mendukung struktur if, else if, dan else secara penuh.

Aturan Penulisan

Sintaks percabangan pada pseudocode kita menggunakan kata kunci bahasa Inggris untuk menjaga kedekatan dengan bahasa pemrograman modern. Setiap blok percabangan wajib ditutup.

  • 1
    if <kondisi> then

    Blok kondisi pertama. Kode di bawahnya akan dieksekusi jika kondisinya bernilai true. Kata kunci then wajib disertakan di akhir baris.

  • 2
    else if <kondisi> then

    Kondisi alternatif jika kondisi if sebelumnya tidak terpenuhi. Kamu bisa menggunakan else if lebih dari satu kali.

  • 3
    else

    Blok terakhir yang akan dieksekusi jika semua kondisi di atasnya bernilai false. Blok ini bersifat opsional.

  • 4
    endif

    Setiap struktur percabangan wajib diakhiri dengan kata kunci endif agar converter tahu batas akhir blok logika tersebut.
