Dokumentasi Struktur Program Kamus

Kamus

Selain Kamus lokal yang dideklarasikan di dalam blok Program, pseudocode di aplikasi ini juga mendukung Kamus Global yang dideklarasikan di luar dan sebelum program utama. Bagian ini membahas apa saja yang boleh dideklarasikan secara global serta urutan penulisannya yang baku.

Deklarasi Kamus Global

Kamus Global dideklarasikan di top level, sebelum blok Program dimulai. Isinya dapat diakses oleh Fungsi, Procedure, maupun Program utama. Ada tiga jenis deklarasi yang didukung:

  • 1
    constant

    Mendeklarasikan nilai tetap yang tidak dapat diubah selama program berjalan.
    Contoh: constant NMAX int = 10.

  • 2
    type ... struct

    Mendefinisikan tipe data bentukan (composite type) yang terdiri dari beberapa isi/field dengan tipe data masing-masing.

  • 3
    type ... array

    Mendefinisikan alias tipe untuk kumpulan data sejenis (array) berdasarkan ukuran dan tipe elemen yang sudah ditentukan, termasuk tipe struct di atas.

Catatan: Nama tipe struct dan array yang dideklarasikan di Kamus Global bersifat global dan dapat langsung dipakai sebagai tipe data di dalam Kamus lokal milik Fungsi, Procedure, maupun Program.

Urutan Struktur Program

Setelah Kamus Global dideklarasikan, urutan penulisan blok pada satu berkas pseudocode wajib mengikuti tahapan berikut, dari atas ke bawah:

  • 1
    Kamus Global

    Deklarasi constant dan type yang berlaku untuk seluruh berkas, ditulis paling atas.

  • 2
    Fungsi

    Kumpulan definisi fungsi yang mengembalikan nilai, ditulis setelah Kamus Global dan sebelum Procedure.

  • 3
    Procedure

    Kumpulan definisi prosedur (tanpa nilai balik), ditulis setelah seluruh Fungsi dan sebelum Program utama.

  • 4
    Program [NamaProgram] ... endprogram

    Blok terakhir dan wajib ada satu kali, berisi Kamus lokal dan Algoritma utama yang menjalankan program.
