Dokumentasi Starter Awal Pengenalan

Pengenalan

Setiap program pseudocode yang akan dikonversi ke Golang di aplikasi ini wajib mengikuti kerangka dasar yang standar. Kerangka ini memastikan converter mengenali mana bagian deklarasi data dan mana bagian logika program.

Struktur Utama

Sintaks pseudocode di aplikasi ini dibagi menjadi tiga blok utama yang ditulis secara berurutan:

  • 1
    Program [NamaProgram]

    Baris pertama yang wajib ada untuk mendefinisikan nama dari program tersebut. Nama program tidak boleh mengandung spasi.

  • 2
    Kamus:

    Blok tempat kamu mendeklarasikan semua variabel beserta tipe datanya sebelum variabel tersebut digunakan.

  • 3
    Algoritma:

    Blok utama tempat kamu menuliskan logika program, operasi matematika, input/output, dan struktur kontrol lainnya.
