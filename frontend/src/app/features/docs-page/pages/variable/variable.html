Variabel & Tipe Data

Variabel adalah tempat untuk menyimpan sebuah nilai atau data. Dalam standar penulisan aplikasi ini, setiap variabel wajib dideklarasikan terlebih dahulu di dalam blok Kamus: sebelum bisa digunakan di dalam blok Algoritma:.

Tipe Data yang Didukung

Saat mendeklarasikan variabel, kamu harus menentukan tipe datanya. Berikut adalah tipe data dasar yang bisa digunakan di aplikasi ini:

  • 1
    integer

    Digunakan untuk menyimpan angka bilangan bulat, baik positif maupun negatif (contoh: 10, -5, 0).

  • 2
    real

    Digunakan untuk angka desimal atau pecahan (contoh: 3.14, 0.5). Nilai ini nantinya akan dikonversi menjadi float64 di Golang.

  • 3
    string

    Digunakan untuk menyimpan teks. Nilai string wajib diapit oleh tanda kutip ganda (contoh: "Halo Dunia").

  • 4
    boolean

    Tipe data logika yang hanya bisa menampung dua kondisi: true (benar) atau false (salah).
